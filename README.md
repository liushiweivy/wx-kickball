# 闪身步 · 弹踢道场（wx-kickball）

弹反玩法 × 花鼓灯身法包装的**微信小游戏**：敌人从城楼发球，你用「闪身步」穿球、用「踢」把能量弹反弹回去打敌人。七阵通关，纯 Canvas、零素材零依赖（音效用 WebAudio 合成）。

## 玩法

- **白球（能量弹）**：球贴身前一瞬间按 **踢** = 完美反弹，球变金色飞回敌人，掉血 + 涨敌人架势；按早了只能把球踢偏保命，自己涨架势。
- **红球（危）**：踢不了，硬吃 26 血。只能按 **闪身**，用无敌帧（0.2s）从球上穿过去。
- **架势**：自己架势满 → 崩体硬直 1.1s；敌人架势满 → 踉跄 2.5s，此时踢回金球命中 = **忍杀**，直接清空一管血。
- 踢有 0.3s 冷却，乱按无法覆盖判定窗 —— 要看球出手。
- 七阵：巡场武生 → 疾风刀客 → 赤甲教头（两管血）→ 夜鹞子 → 铁猿双煞（双血条）→ 危球天师 → 镇场宗师·白眉（三管血）。

## 操作（触屏）

| 按键 | 作用 |
|---|---|
| ◀ ▶（左下） | 左右移动，对齐来球 |
| 闪身（右下·青） | 向当前移动方向快速闪身，含无敌帧 |
| 踢（右下·金） | 反弹 / 踢偏来球，带冷却扇形指示 |

死亡只重开当前波。

## 花鼓灯梗（闪身步）

玩法包装取自 2026 年爆火的安徽花鼓灯「闪身步」梗（北京舞蹈学院赵铁春教学视频，全网 80 亿播放，招牌动作是侧撤身）：

- **闪身步**：闪身带侧倾身姿与残影，穿球成功飘字「闪身步！」，正是花鼓灯的侧闪步法。
- **浪子踢球**：完美反弹飘字「浪子踢球！」—— 花鼓灯里本就有同名动作「浪子踢球」。
- **隆咚哐**：敌人蓄力按鼓点三等分，手下三盏鼓灯逐一点亮，前两拍鼓声、第三拍出球，配三点指示灯。
- **狗熊哆嗦毛**：自己架势崩了飘「哆嗦毛…」（配对的山东鼓子秧歌梗）。
- **伞森步**：王嘉尔把「闪身步」念成「伞森步」—— 无伤通关战功页称号「伞森步 · 身法大成」，残血通关则是「鼓架子还得再练」。

## 运行

微信开发者工具 → 导入项目 → 选择本目录 → 类型选「小游戏」→ AppID 选**测试号/游客模式**（无 AppID 可玩模拟器；真机预览需微信扫码）。

> `project.config.json` 里的 `wx6ac3f5090a6b99c5` 是小游戏游客模式的固定 AppID；换成你自己的 AppID 即可发布。

浏览器里也能跑（core/render/audio 均无 wx 依赖）：

```powershell
node "$env:TEMP\kick-serve.mjs"   # 或任意静态服务器，根目录指向本项目
# 打开 http://localhost:8778/harness/index.html ，鼠标点按键
```

## 测试

```powershell
node --test tests/core.test.mjs tests/balance.test.mjs
```

- `core.test.mjs`：17 项机制测试（三档踢、危球、闪身无敌帧、架势、忍杀、波次、死亡重开、鼓点节拍与飘字）
- `balance.test.mjs`：bot 平衡验证 —— 会玩的 bot 多种子满血通关；乱按踢的 bot 必败；站桩时敌人不掉血（踢球是唯一输出）

## 结构

```
game.js              小游戏入口
game.json            竖屏配置
project.config.json  工程配置
js/
  core.js            战斗内核（纯逻辑 UMD，Node 可测）
  render.js          Canvas 表现层（场景/火柴人/球/HUD/虚拟按键，复用 core 的节拍助手）
  audio.js           WebAudio 合成音效
  main.js            wx 适配：画布/DPR、触摸、固定 60Hz 步长
tests/               node:test
harness/             浏览器验证壳（wx shim），不进小游戏包
```
